# 三个模块创新角度查重表（撞车 / 不撞车）

> 目标：把三个模块能想到的所有创新角度，逐一与现有技术对照，标注"撞车 / 部分撞车 / 不撞车"。
> 结论：每个模块各找到 **1 个不撞车角度**，作为最终创新点；其余角度均已有人发表或价值有限。
> 检索口径：中英文双渠道，2026-10 交叉验证。

---

| DCNv4 形变卷积 | ✅ 撞车 | Dynamic Head（审稿人已点名） | 结构调用，放弃 |
| 门控自适应融合 | ✅ 撞车 | Dynamic Head 注意力门控 | 已发表，放弃 |
| 深浅双路径 detail/semantic | ✅ 撞车 | 通用双路径设计 | 无区分度，放弃 |
| 高频保持（HFRM） | ✅ 撞车 | SF-YOLO、Spectra-Net 等频域增强 | 已发表，放弃 |

## 模块三：损失优化（原 SAIW → 尺度归一化最大均值差异分布匹配回归损失）

| 创新角度 | 是否撞车 | 撞车的具体工作（论文 / 机制） | 结论 |
|---|---|---|---|
| NWD 高斯 Wasserstein | ✅ 撞车 | NWD（ISPRS 2022，小目标奠基） | 现用方法，审稿人点名 |
| GWD / KLD / BD / ProbIoU | ✅ 撞车 | 高斯封闭式一族（ICML2021 等） | 已发表，放弃 |
| Inner-IoU | ✅ 撞车 | Inner-IoU | 现用方法 |
| Shape-IoU / Focaler-ShapeIoU / SA-FSIoU | ✅ 撞车 | 形状感知一族 | 已发表，放弃 |
| MPDIoU / Wise-IoU / Focaler-IoU 等 IoU 变体 | ✅ 撞车 | IoU 组合杂交（上百变体） | 最饱和，放弃 |
| 各向异性高斯 Wasserstein（AGW） | ✅ 撞车 | 各向异性高斯 + Bhattacharyya（Neurocomputing 2025） | 已发表，放弃 |
| 对数极坐标尺度不变度量 | ⚠️ 部分撞车 | Polar Loss（极坐标非 log-polar）、RSINet（跟踪） | log 部分价值有限，放弃 |
| 边界度量 | ⚠️ 部分撞车 | EWD（旋转框）；轴对齐小框逐边边界距离有局部空档 | 局部空档，成色偏薄 |
| **MMD 作为框回归损失** | ✅ **不撞车** | MMD 只用于域适应/特征对齐，从未做框回归损失（中英文检索确认） | **最终采用** ✓ |
| **Sinkhorn/熵正则 OT 作为回归损失原语** | ✅ **不撞车** | Sinkhorn 只在标签分配用（RTP-DETR、OTA），从未做回归损失 | **备选/可融合** ✓ |

## 汇总：三个最终创新点（都不撞车）

| 模块 | 最终创新点 | 所属数学家族 | 与最接近工作的区别 |
|---|---|---|---|
| 特征提取 | 尺度等变特征提取 | 群等变性 | 首次用于 VisDrone 航拍小目标；现有全是"尺度感知"启发式 |
| 特征融合 | 几何中位数鲁棒融合 | 鲁棒统计 | 现有 FPN/PANet/BiFPN/ASFF 全是加权平均，我用抗离群 M-estimator |
| 损失优化 | MMD/Sinkhorn 分布匹配回归 | 分布匹配 | MMD 从未做框回归；Sinkhorn 只在标签分配用过 |

三个创新点分属三个互不重叠的数学家族，审稿人点名的 Dynamic Head、DCNv4、NWD、Inner-IoU 均不在其中。
