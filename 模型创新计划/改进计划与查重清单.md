## 一、论文叙事顺序（三个模块按网络流程）

### 叙事主线（写进引言/摘要）
针对航拍小目标的尺度困境，本文在**表征、融合、回归**三个层面分别引入**群等变性、鲁棒统计、分布匹配**三种严谨数学工具，把"尺度"从训练目标升级为结构属性，区别于现有"加权/调参"式启发方法。

### 模块一：尺度等变细节语义双路径特征提取模块（特征提取 / backbone）
| 项目 | 内容 |
|---|---|
| 现状 | 深浅双路径 + token 混合 + CGLU + 门控 + DCNv4，全是拼装 |
| 改进方向 | 把"学会抗尺度"升级为"结构上数学保证尺度一致" |
| 具体改动 | 只在细节分支里把部分卷积换成尺度等变卷积（escnn/e2cnn 现成库），语义分支保持；控制改动范围 |
| 理论卖点 | 首个把尺度等变网络用于航拍小目标检测（此前只有分类/跟踪/KITTI） |

### 模块二：小目标先验引导的几何中位数鲁棒金字塔融合模块（特征融合 / neck）
| 项目 | 内容 |
|---|---|
| 现状 | P2/P3 先验 + 门控调制 + 可学习权重加权求和 |
| 改进方向 | 把加权平均换成抗离群的鲁棒聚合 |
| 具体改动 | 对每个空间位置的 4 尺度响应向量，用可微几何中位数（Weiszfeld 迭代平滑版 / Moreau 包络）替代加权求和；先验与门控保留 |
| 理论卖点 | 首个把鲁棒 M-estimator 引入检测颈部跨尺度聚合（FPN/PANet/BiFPN/ASFF 全是凸组合） |

### 模块三：尺度归一化最大均值差异分布匹配回归损失（损失优化 / head）
| 项目 | 内容 |
|---|---|
| 现状 | 面积加权 Inner-IoU + NWD + 中心偏移，全是已发表方法 |
| 改进方向 | 把"框 vs 框"从"矩形比大小"改成"两团点分布匹配" |
| 具体改动 | 在 loss.py 里，把预测框和真值框各采样成一团点（4 角 + 中心 + 框内均匀网格点），用高斯核 MMD² 度量两团点分布差异作回归损失；保留尺度归一化项 |
| 理论卖点 | 首个把 MMD/分布匹配作为框回归损失原语（MMD 此前只做域对齐，Sinkhorn 只做标签分配） |

## 二、实验实施顺序（与叙事顺序相反，按改动量从小到大）

1. **先做模块三（损失）**——改动最小（只改回归损失一段），最快验证
2. **再做模块二（融合）**——改动中等（替换聚合算子）
3. **最后做模块一（特征）**——改动最大（尺度等变训练不稳需调），作为理论主卖点

> 备选：若尺度等变训练太难，模块一退一步用神经 ODE 连续深度重新解释细节路径。但注意 HRL-Det 已用神经 ODE 做航拍检测（用途是 RL 状态演化），需划清边界——故首选尺度等变。
