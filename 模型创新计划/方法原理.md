# 尺度条件化（Scale-Conditioning）：面向航拍小目标检测的原理与方法

> 本文的理论主线：把"目标尺度"作为显式物理条件，重建进检测器三个核心算子（特征提取、特征融合、回归损失）的核心参数里，从而把"尺度"从训练目标升级为结构属性。
> 阅读约定：每个公式后附【白话】解释，便于对照理解。三个模块均以"性质 + 证明"的形式给出理论贡献。

---

## 1. 问题的原理表述

### 1.1 尺度无关假设及其违背

现有检测器（含 RT-DETR）的每个核心算子，都隐含一个**尺度无关假设**：算子的核心超参数 θ 是常数，与目标尺度无关。具体到三个算子：

| 算子 | 隐含假设 | 航拍小目标如何违背它 |
|---|---|---|
| 特征提取（卷积核/感受野） | 尺度是离散、均匀的（如固定 1/2/4/8 档） | 尺度是**连续**的，且**集中在小的一端**（对数分布） |
| 特征融合（加权平均） | 所有尺度**同等可信** | 浅层（小目标所在）**噪声大**，可信度低 |
| 回归损失（IoU/高斯距离） | 同样像素偏移对大小框**同等重要** | 小框偏 2 像素是"半条命"，大框偏 2 像素无所谓 |

【白话】这三条是同一个病根：现有方法把"尺度"当成可以忽略的变量，而小目标恰恰是尺度极端、信噪比极低的情况。

### 1.2 三种设计范式

算子核心超参数 θ 的三种取值方式：

| 范式 | 形式 | 含义 | 代表 |
|---|---|---|---|
| 常数化 | θ = c | 尺度无关 | 绝大多数现有方法 |
| 自适应 | θ = g(data) | 从数据隐式学习，不显式知道"尺度" | SimConv、MMDAgg、Soft Medoid |
| **尺度条件化（本文）** | **θ = f(s)** | 把目标尺度 s **显式**耦合进算子 | —— |

### 1.3 核心原则（定义）

**尺度条件化（Scale-Conditioning）**：检测器算子的核心超参数 θ，写成目标局部尺度 s 的显式函数 θ = f(s)，使算子的行为随目标尺度发生结构化改变。

**为什么"显式"优于"自适应"**：小目标是**极端尺度分布**，数据驱动的自适应在这种分布下学不出正确参数（极端尺度样本太稀疏、梯度信号不足）；而尺度条件化把正确的物理先验**直接注入**。

【白话】自适应是"让网络自己猜"，尺度条件是"把'目标多大'这个已知物理量直接告诉网络"。

---

## 2. 尺度条件化在三个算子上的实例化（总览）

三者共用同一原则 θ = f(s)，只是 θ 和 s 不同：

| 模块 | 算子 | 被条件化的旋钮 θ | 尺度来源 s | 函数 f |
|---|---|---|---|---|
| 一（特征） | 等变卷积 | 尺度核密度 ρ(log σ) | 局部尺度 | ρ ∝ p(s) |
| 二（融合） | 鲁棒聚合 | 崩溃点 β | 金字塔层级 l | β(l) |
| 三（回归） | MMD | 核带宽 σ_k | 框面积 | σ_0·√A |

下面第 3、4、5 节分别给出三个模块的完整形式化与"性质 + 证明"。

---

## 3. 模块一：尺度条件核密度等变卷积（特征层）

### 3.1 预备：尺度等变卷积

尺度等变卷积把卷积核定义在尺度群 G = {σ > 0} 上（σ 为尺度因子）。设输入特征 f、尺度变换 T_σ（把图像放大 σ 倍），**等变性**要求：

$$f(T_\sigma x) = T_\sigma f(x)$$

即"先缩放图像再提特征"等于"先提特征再缩放特征"。

Sosnovik 的离散尺度等变取有限离散尺度集 {σ_1, …, σ_K} = {1, 2, 4, 8}，每个尺度一个核、**均匀**分配。

### 3.2 本文：连续对数尺度 + 小目标先验核密度

本文两点改进：
1. 尺度群从**离散集**改为**连续对数坐标** log σ（尺度是乘法关系，对数坐标使其均匀）；
2. 核密度 ρ(log σ) 由**小目标尺度先验 p(s)** 条件化，不再均匀：

$$\rho(\log\sigma) \propto p(s)$$

航拍图中目标尺度 s 呈对数分布、集中在小端，故 p(s) 在小的 s 处大 → **小尺度端核更密**。

### 3.3 性质 1（等变性保持）

**命题**：非均匀核密度 ρ(log σ) ∝ p(s) **不破坏**尺度等变性，即对任意 σ，f(T_σ x) = T_σ f(x) 仍成立。

**证明**：等变性由卷积核满足的 steerability 约束保证（核张成尺度群的表示、核间满足线性约束），该约束只与核的"方向结构"有关，与核密度 ρ 的取值无关；ρ 只决定"每个尺度分配多少个核"，不改变"每个核是否等变"。故偏置核密度下等变性保持。∎

【白话】偏心小目标不会破坏"尺度一致"这个数学保证——偏置只影响"预算分配"，不影响"是否等变"。

### 3.4 性质 2（小尺度分辨率提升）

**命题**：设对数尺度区间 [a, a+δ] 内分配的等变核数量为 N(a) = ∫_a^{a+δ} ρ(log σ) dσ。若 ρ 在 log σ 上单调递减（小尺度核更密），则对 a < b 有 N(a) ≥ N(b)。

**证明**：因 ρ 随 σ 单调递减，对同宽对数区间有 ∫_a^{a+δ} ρ dσ ≥ ∫_b^{b+δ} ρ dσ（a < b）。∎

【白话】性质 2 说明"小尺度端分到更多等变核 = 小目标的尺度被分得更细"。这就是"尺度条件化"在特征层的意义：把表征预算（representation budget）向小目标尺度倾斜。

## 4. 模块二：尺度条件崩溃点鲁棒共识（融合层）

### 4.1 预备：崩溃点（Breakdown Point）

设融合算子 A 把第 l 层的响应集合 Y_l = {y_1, …, y_K} 聚合成一个输出 ŷ = A(Y_l)。**崩溃点 β** 定义为算子能容忍的最大离群响应比例——离群比例一旦超过 β，输出可被任意破坏。

- 加权平均 ŷ = Σ w_i y_i：β = 0（单个离群即可任意破坏）
- 几何中位数 argmin_y Σ‖y − y_i‖：β = 1/2，但**对所有层固定**

### 4.2 本文：尺度条件崩溃点

把崩溃点写成金字塔层级 l 的**显式函数**：

$$\beta = \beta(l), \quad \text{浅层（}l\text{ 小，小目标、噪声大）}\beta\text{ 大，深层 }\beta\text{ 小}$$

实现用**截尾均值**（trimmed mean）：按 β(l) 比例裁掉每层最离谱的响应再平均。

### 4.3 性质 1（崩溃点-噪声匹配）

**命题**：设第 l 层的离群响应比例为 ε(l)，且浅层噪声更大（ε(l) 随 l 递减）。取 β(l) = ε(l)，则融合在每层同时满足：(a) 对 ε(l) 以内的离群鲁棒；(b) 不裁掉正常响应。

**证明**：崩溃点 β(l) 的含义即"可容忍 β(l) 比例的离群"。取 β(l) = ε(l)，恰好容忍该层全部离群、且不裁正常响应，(a)(b) 同时成立。∎

### 4.4 性质 2（固定崩溃点的次优性）

**命题**：固定崩溃点 β ≡ β0 的融合无法在所有层同时最优，而尺度条件 β(l) = ε(l) 可以。

**证明**：固定 β0 时，对噪声 ε(l) > β0 的层（浅层），离群未被完全容忍、融合被破坏；对噪声 ε(l) ≪ β0 的层（深层），正常响应被过度裁减、丢失有效信息。除非 β0 同时匹配所有层的 ε(l)（通常不成立），固定崩溃点必在至少一层次优；尺度条件 β(l) = ε(l) 逐层匹配，故最优。∎

【白话】性质 2 是模块二的理论卖点：固定力度要么抗不住噪声大的浅层、要么浪费干净的深层；只有"让抗噪力度跟着尺度走"才对。

## 5. 模块三：尺度条件核带宽 MMD 回归（损失层）

### 5.1 预备：核均值嵌入与 MMD

设 H 为再生核希尔伯特空间（RKHS），取高斯核

$$k(u, v) = \exp\left(-\frac{\|u-v\|^2}{2\sigma_k^2}\right)$$

分布 P、Q 的核均值嵌入为 μ_P = E_{x~P}[k(x,·)]、μ_Q = E_{y~Q}[k(y,·)]，则 MMD 定义为它们在 H 中的距离：

$$\text{MMD}(P, Q) = \|\mu_P - \mu_Q\|_H$$

其平方的经验估计（V 统计量）为

$$\text{MMD}^2(P,Q) = \frac{1}{n^2}\sum_{i,j} k(x_i,x_j) + \frac{1}{m^2}\sum_{i,j} k(y_i,y_j) - \frac{2}{nm}\sum_{i,j} k(x_i,y_j)$$

【白话】MMD 就是"把两堆点映射到高维空间，量它们的平均像有多近"，点越重合 MMD 越小。

### 5.2 框的点集表示

轴对齐框 b = (x, y, w, h) 表示为四角点点集：

$$P_b = \{p_1,p_2,p_3,p_4\},\quad p_i \in \{(x-\tfrac{w}{2},y-\tfrac{h}{2}), (x+\tfrac{w}{2},y-\tfrac{h}{2}), (x-\tfrac{w}{2},y+\tfrac{h}{2}), (x+\tfrac{w}{2},y+\tfrac{h}{2})\}$$

真值框同理得 P_gt = {g_1,…,g_4}。（可选：加中心点、四边中点构成 8/9 点集增强稳定性。）

### 5.3 尺度条件核带宽（核心创新）

框的线性尺度 s = √(w^gt·h^gt)（面积开方，近似对角长度）。核带宽写成尺度的**显式函数**：

$$\sigma_k = \sigma_0 \cdot s$$

σ_0 为无量纲常数（超参数，如 0.5）。这就是"尺度条件化"在损失层的体现：**θ = σ_k，s = 框尺度，f(s) = σ_0·s**。

【白话】小框带宽小 = "紧"尺子，偏一点就量出大误差；大框带宽大 = "松"尺子。

### 5.4 完整损失函数

$$L_{\text{mmd}}(b, b^{gt}) = \frac{1}{16}\sum_{i,j=1}^{4} k(p_i, p_j) + \frac{1}{16}\sum_{i,j=1}^{4} k(g_i, g_j) - \frac{1}{8}\sum_{i,j=1}^{4} k(p_i, g_j)$$

其中 k 的带宽 σ_k = σ_0·√(w^gt·h^gt)。

> 实现注：真值框自身项 Σ k(g_i, g_j) 在训练中为常数（GT 固定），可省略；预测框自身项 Σ k(p_i, p_j) 起"框尺度正则"作用，保留。

### 5.5 性质 1（尺度不变性）

**命题**：当 σ_k ∝ s 时，损失对两框的**同时等比缩放**不变：L(k·b, k·b^gt) = L(b, b^gt)。

**证明**：等比缩放 k 倍后，点坐标 x → kx，尺度 s → ks，带宽 σ_k → kσ_k，于是

$$k(u,v) = \exp\left(-\frac{\|ku-kv\|^2}{2(k\sigma)^2}\right) = \exp\left(-\frac{\|u-v\|^2}{2\sigma^2}\right)$$

核值不变，故 MMD² 不变。∎

### 5.6 性质 2（小目标敏感性）

**命题**：对固定绝对位移 δ，尺度越小惩罚越重。

**证明**：固定位移 δ 下，交叉项核值为

$$k(p_i, g_j) = \exp\left(-\frac{\|\delta\|^2}{2\sigma_0^2 s^2}\right)$$

s 越小，指数越小、核值越小、L_mmd 越大，即惩罚越重。∎

【白话】同样的 2 像素偏移，对小框是"大错"、对大框是"小错"，这个损失自动分开。

---

## 6. 三者的自洽性：同一个原则 θ = f(s)

三个模块表面独立，实则是**同一个原则在三个算子上的投影**，共享数学结构 **θ = f(s)**（见第 2 节总览表）。一句话概括：

> 检测器对尺度的处理，不应是"常数"（尺度无关），也不应是"隐式学习"（自适应），而应是把目标尺度作为显式物理条件，重建进每一个算子的核心参数——这就是"尺度条件化"。

## 7. 与现有工作的理论区别

| 本文 | 现有 | 区别 |
|---|---|---|
| 尺度条件核带宽 MMD 回归 | NWD/GWD/KLD（高斯封闭式）、MMD 域适应 | MMD 从未做框回归；带宽由尺度显式决定（非固定、非数据挑） |
| 尺度条件崩溃点鲁棒共识 | 加权平均（β=0）、Soft Medoid（β 固定 0.5） | 崩溃点由尺度层级显式决定 |
| 尺度条件核密度等变卷积 | Sosnovik（离散均匀）、SimConv（连续无偏置） | 连续 + 小目标尺度先验加权 |

三个创新点分属三个互不重叠的数学家族（群等变性、鲁棒统计、分布匹配），审稿人点名的 Dynamic Head、DCNv4、NWD、Inner-IoU 均不在其中。
